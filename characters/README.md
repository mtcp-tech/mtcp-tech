# Портреты персонажей — требования к файлам

Сейчас в этой папке только стаб-файлы (текст внутри `.jpg`, не изображение) — замените их
реальным артом под теми же именами и расширением, ничего в коде менять не придётся
(`app/src/content/characters.ts`, поле `portraitSrc`).

## Файлы

| Файл | Персонаж | Эпизоды |
|---|---|---|
| `clockmaker.jpg` | Часовщик | 1–6 |
| `artist.jpg` | Художник | 2 |
| `letter-keeper.jpg` | Хранитель письма | 3 |
| `swan.jpg` | Лебедь | 4 |
| `boatman.jpg` | Лодочник | 5 |

## Требования к изображению

- **Формат:** JPG.
- **Пропорции:** квадрат 1:1 — изображение показывается в круглой рамке (`object-fit: cover`,
  CSS вырезает круг из центра кадра), так что углы кадра всё равно не видны. Главное — держать
  лицо/центр композиции в середине кадра, с запасом по краям.
- **Размер:** минимум 300×300 px, рекомендовано 600×600 px (рамка на экране — 150×150 CSS-px,
  запас на Retina/плотные экраны).
- **Вес файла:** до ~250 КБ на файл — квест идёт 60–75 минут на мобильном интернете на улице,
  каждый лишний килобайт на старте эпизода — это секунды ожидания у реального игрока.
- **Фон:** любой — виден только внутри круга, обрезка не требует прозрачности/однотонного фона.

## Настроение (US-09a/10/11)

Один файл на персонажа, не три — «тёплое»/«задумчивое»/«обычное» настроение (`Mood` в
`content/types.ts`) передаётся CSS-подсветкой поверх этого же портрета
(`character-sprite--warm` светится золотым, `character-sprite--thoughtful` приглушён), не
отдельным рисунком. Если позже понадобится по-настоящему другое изображение на каждое
настроение — это смена архитектуры (новое поле вместо одного `portraitSrc`, например
`portraitSrc: { normal, warm, thoughtful }`), не просто добавление файлов.

## Что будет, если файл отсутствует или не открывается

Экран не ломается: `catscene.ts` слушает `onerror` на `<img>` и прячет картинку, оставляя
просто круглую золотую рамку с подсветкой — так сейчас выглядят все 5 персонажей, пока здесь
лежат стаб-файлы.
